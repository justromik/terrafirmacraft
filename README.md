# TFC Horse Chests — NeoForge 1.21.1

Самостоятельный аддон, добавляющий лошадям TerraFirmaCraft сундук на **15 ячеек (5 × 3)**.
Он реализует нужную механику напрямую и не использует код, API или хранилище Horses With Chests.
Horses With Chests устанавливать не требуется; совместимость с ним не проверена.

## Скачать

- [Готовый мод .jar](https://github.com/justromik/terrafirmacraft/raw/refs/heads/main/downloads/tfc-horse-chests-neoforge-1.21.1-1.0.0.jar)
- [Тот же мод в ZIP](https://github.com/justromik/terrafirmacraft/raw/refs/heads/main/downloads/tfc-horse-chests-install.zip) — распакуйте jar в `mods`.
- [Контрольные суммы SHA256](downloads/SHA256SUMS)

## Установка

Требуется Minecraft **1.21.1**, Java **21**, NeoForge **21.1.234 или новее в ветке 21.1**,
TerraFirmaCraft **4.x** и его обычные зависимости (Patchouli).
Проверочная конфигурация: NeoForge 21.1.234, TFC 4.2.12, Patchouli 1.21.1-93.
Другие выпуски TFC 4.x отдельно не проверялись.

Положите `tfc-horse-chests-neoforge-1.21.1-1.0.0.jar` в папку `mods`.
На выделенном сервере аддон нужен **и на сервере, и у всех игроков**.
Перед первым запуском сделайте резервную копию мира.

## Использование

1. Возьмите пустой деревянный сундук и нажмите ПКМ по взрослой, достаточно знакомой с вами лошади TFC.
   Используется проверка приручения самого TFC; неприручённые лошади и жеребята не принимают сундук.
2. Один сундук расходуется в выживании; в творческом режиме не расходуется.
3. Сядьте на лошадь и нажмите клавишу инвентаря (**E** по умолчанию) — откроются 15 ячеек и ваш инвентарь.
4. С земли сундук открывается **Shift + ПКМ пустой рукой**.
5. Чтобы открыть обычное окно седла/брони, сойдите с лошади, возьмите предмет в основную руку
   (например седло) и нажмите **Shift + ПКМ**.

Поддерживаются сундуки из тега `c:chests/wooden`, включая деревянные сундуки TFC.
Сундук с предметами внутри не устанавливается: сначала освободите его.
Можно надеть только один сундук. Снятие отдельно не предусмотрено.
Лошадь другого владельца не принимает сундук и не даёт доступа к его содержимому.
Внешний вид лошади не меняется: модели и текстуры не добавляются.

Предметы сохраняются в данных лошади, включая выгрузку чанка и перезапуск мира.
При смерти лошади сундук и предметы попадают в обычные дропы сущности
(поэтому подчиняются `doMobLoot` и обработчикам дропа других модов).
Не удаляйте аддон из мира, пока не забрали вещи из лошадей: без него эти вещи недоступны.

## Сборка

```sh
./gradlew build
```

Нужен полный JDK 21. Готовый jar находится в `build/libs/`.
Сторонние моды не включаются внутрь jar. Gradle Wrapper 8.8 проверяет SHA256 дистрибутива.

Для запуска клиента или проверок положите официальные TFC 4.2.12 и Patchouli 1.21.1-93
в игнорируемую папку `dev-mods/`:

```sh
./gradlew runClient
./gradlew -PgameTests runGameTestServer
```

GameTest использует настоящих лошадей TFC. Исходники проверок из `src/gametest/` подключаются
только с `-PgameTests`; не собирайте распространяемый jar с этим флагом.
Проверки не заменяют ручную проверку отрисовки клиентского окна.
