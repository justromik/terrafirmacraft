# Проверка сборки

Дата: 2026-10-21.
Minecraft 1.21.1, NeoForge 21.1.234, TFC 4.2.12, Patchouli 1.21.1-93, JDK 21.

Сервер GameTest завершился с кодом 0: **7 обязательных тестов из 7 прошли**.

- ПКМ с сундуком обрабатывается событием взаимодействия; расходуется ровно один сундук,
  повторная установка запрещена; 15 слотов груза и 36 слотов игрока.
- Сундук, предмет и количество в последней (15-й) ячейке сохраняются после сериализации
  настоящей лошади TFC и восстановления новой сущности из сохранённых данных.
- Чужой владелец и недостаточное знакомство TFC блокируют установку.
- Shift-клик работает в обоих направлениях и сохраняет количество предметов.
- Событие смерти добавляет сундук и содержимое в дроп ровно один раз.
- Команда OPEN_INVENTORY, которую отправляет клавиша E, открывает CargoMenu верхом,
  не спешивая игрока. Используется настоящий ServerPlayer и штатный обработчик команды;
  имитируется только отсутствующий клиентский сетевой транспорт.
- Дубовый сундук TFC принимается; удалённый предмет не восстанавливается после загрузки.

Команда: `./gradlew -PgameTests runGameTestServer`.
В облачной среде для Java настроен штатный HTTPS-прокси и системное хранилище сертификатов.
Для серверного запуска использован `-x downloadAssets`: индекс ресурсов 17 получен с официального
сервера Mojang, загрузка оставшихся клиентских звуков/текстур серверу не требуется.
Это не клиентская проверка: отрисовка окна и реальное клиент-серверное соединение вручную не проверены.
Файловый перезапуск мира/выгрузка чанков отдельно не воспроизводились; проверена используемая
ими сериализация сущности.

Horses With Chests в тестовой конфигурации отсутствовал. Этот аддон реализует механику самостоятельно;
совместимость одновременной установки двух модов не заявляется.
